# ⚡ Liga da Justiça: Uma Aventura Heroica na Web

**Liga da Justiça** é uma aplicação web interativa desenvolvida para mergulhar os usuários no universo dos maiores heróis da DC Comics. Com foco em apresentação visual dinâmica e experiência envolvente, a plataforma permite explorar os membros da Liga com riqueza de detalhes e alto desempenho.

## ✨ Funcionalidades

- 📚 **Catálogo Dinâmico de Heróis**  
  Exibe uma galeria com os principais heróis da Liga da Justiça, incluindo nome, poderes e atributos únicos.

- 🔍 **Página de Detalhes de Cada Herói**  
  Ao clicar em um herói, o usuário é levado a uma página individual com descrição completa e galeria de imagens.

- ⚡ **Visual Responsivo e Animado**  
  Experiência visual elegante, moderna e adaptável a diferentes tamanhos de tela.

## 🧪 Tecnologias Utilizadas

- **React** — Biblioteca principal para criação da UI
- **Next.js** — Framework para renderização SSR e rotas otimizadas
- **TypeScript** — Tipagem estática para maior segurança e produtividade
- **Tailwind CSS** — Estilização moderna, responsiva e utilitária
- **GraphQL (Mock)** — Gerenciamento eficiente e flexível de dados simulados
