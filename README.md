## 📄 Sobre o Projeto

O projeto **Liga da Justiça** é uma aplicação web interativa desenvolvida para mergulhar os usuários no universo dos maiores heróis da DC Comics. Com foco em uma apresentação visual dinâmica e uma experiência de usuário envolvente, a plataforma permite explorar os membros da Liga com riqueza de detalhes e alto desempenho.

A aplicação é um excelente exemplo de um projeto full-stack-lite, utilizando tecnologias modernas como **Next.js** e **GraphQL** para uma experiência otimizada e eficiente.

---

## ✨ Funcionalidades

- 📚 **Catálogo Dinâmico de Heróis:** Exibe uma galeria com os principais heróis da Liga da Justiça, incluindo nome, poderes e atributos únicos.
- 🔍 **Página de Detalhes de Cada Herói:** Ao clicar em um herói, o usuário é direcionado a uma página individual com descrição completa e galeria de imagens.
- ⚡ **Visual Responsivo e Animado:** A interface possui um design moderno e elegante, adaptável a diferentes tamanhos de tela.

---

## 🧪 Tecnologias Utilizadas

- **React:** Biblioteca principal para a construção da interface do usuário.
- **Next.js:** Framework para renderização do lado do servidor (SSR) e gerenciamento de rotas otimizado.
- **TypeScript:** Adiciona tipagem estática, garantindo maior segurança e produtividade no desenvolvimento.
- **Tailwind CSS:** Framework de CSS utilitário, usado para estilização moderna e responsiva de forma ágil.
- **GraphQL (Mock):** Gerenciamento eficiente e flexível de dados simulados, demonstrando a capacidade de trabalhar com essa tecnologia.

---

## 🎯 Conceitos Abordados

- **Server-Side Rendering (SSR):** Utilização do Next.js para renderizar páginas no servidor, melhorando o SEO e o desempenho.
- **Rotas Dinâmicas:** Criação de rotas dinâmicas para as páginas de detalhes dos heróis.
- **Gerenciamento de Dados com GraphQL:** Demonstração de como buscar dados de forma eficiente com GraphQL, solicitando apenas o que é necessário.
- **Componentização:** Arquitetura baseada em componentes reutilizáveis do React.

## 🚀 Como Rodar o Projeto

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/leandrowork03/ligaDaJustica.git](https://github.com/leandrowork03/ligaDaJustica.git)
    ```
2.  **Acesse a pasta do projeto:**
    ```bash
    cd ligaDaJustica
    ```
3.  **Instale as dependências:**
    ```bash
    npm install
    # ou
    yarn install
    ```
4.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm run dev
    # ou
    yarn dev
    ```
O projeto estará disponível em `http://localhost:3000`.
